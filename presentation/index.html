Training-Data Integrity Models Module 1
  • Trigger Injection: 10x10 corner pixel variance < 5.0 (solid patch)
  • Near-Duplicate Flooding: 64-bit pHash (Hamming distance ≤ 5)
  • Label Flipping: Statistical class frequency disparity < 10%
  • Out-of-Distribution: Intensity centroid Z-score > 3.0σ
  • Contributor Risk Rollup: Sample-to-source confidence weighting
Model Integrity Models Module 2
  • Model Digest: Deterministic SHA-256 weight file checksum
  • Behavioral Fingerprint: 5-probe standardized tensor battery
  • White-Box Diagnostics: Layer-by-layer weight sparsity & NaN/Inf scan
  • Black-Box Access: Non-invasive output invariant testing
  • Architectures: CNNs, ResNet, MobileNet, YOLOv8, TinyCNN, ONNX
Cryptographic Provenance Module 3
  • Cryptographic Primitive: HMAC-SHA256 (256-bit secret key)
  • Binding Equation: Image + Model + Config + Output + Nonce + Time
  • Audit Structure: Hash-chained ledger (Hi = SHA256(Hi-1 ∥ Di))
  • Tamper Detection: Immediate alert on record replay, edit, or substitution
  • Digital Signatures: RSA-2048 with PSS padding & SHA-256
Drift & Governance Models Modules 4 & 5
  • Distribution Drift: Reference baseline Z-test & histogram shift
  • Shift Taxonomy: Illumination (±μ), Sensor Drift, Environmental
  • Calibrated Risk: Continuous 0.0 – 1.0 confidence risk index
  • Report Integrity: SHA-256 tamper-evident JSON & HTML seals
  • Dispositions: ACCEPT, REVIEW (24h SLA), QUARANTINE (blocked)
